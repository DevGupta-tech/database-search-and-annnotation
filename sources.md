# Sources

1. **NCBI Protein: NP_000509.1 — hemoglobin subunit beta [Homo sapiens].**  
   https://www.ncbi.nlm.nih.gov/protein/NP_000509.1  
   Supports the query accession and protein identity.

2. **NCBI Gene: HBB, Gene ID 3043.**  
   https://www.ncbi.nlm.nih.gov/gene/3043  
   Supports the HBB gene identity and its relationship to the beta-globin protein.

3. **UniProtKB: P68871 — HBB_HUMAN.**  
   https://www.uniprot.org/uniprotkb/P68871/entry  
   Supports the reviewed human hemoglobin subunit beta annotation and biological context.

4. **UC San Diego, BIMM 143, Lecture 2 (Bioinformatics), BLASTP example.**  
   https://bioboot.github.io/bimm143_W24/class-material/lecture2-BIMM143-large.pdf  
   The lecture's BLASTP example uses NP_000509.1, reports a 147-aa query, shows the nr database and BLASTP settings, and includes the selected hit statistics transcribed in `results/blast_hits.tsv`. The lecture is the provenance for the archived result snapshot.

5. **NCBI BLASTP search page.**  
   https://blast.ncbi.nlm.nih.gov/Blast.cgi?PROGRAM=blastp  
   Public interface for reproducing the search with current database contents.

## Data provenance and integrity
The archived BLAST result statistics are copied from the published lecture example, not invented or recalculated. Since the lecture is a historical teaching example, values and ranking should not be represented as current live NCBI results. If a live result is required, rerun the search at NCBI and replace the result table with the downloaded output.
